BRIGHTLEAF SUPPORT AGENT - RECORDING SCRIPT
===========================================

BEFORE YOU HIT RECORD
---------------------
1. Check the model still answers (AWS keys expire):
       hermes -p supportdemo -z "hi"
   If you get an auth error, paste fresh AWS keys first.

2. Clear old tickets:
       cd ~/hermes-support-demo && ./reset.sh
   (on the VPS: cd /data/workspace/hermes-support-demo && ./reset.sh)

3. Window 1 - the chat:
       hermes -p supportdemo chat

4. Window 2 - tickets appearing live:
       watch -n1 cat ~/hermes-support-demo/data/tickets.json
   (on the VPS: watch -n1 cat /data/workspace/hermes-support-demo/data/tickets.json)

Type /new in the chat wherever the script says NEW CONVERSATION.


SCENE 1 - TROUBLESHOOTING FROM THE HELP ARTICLES
------------------------------------------------
Say:   "Lea answers only from the company's own help articles."

Type:  hi, my hub is blinking orange

Expect: numbered steps (router, power-cycle, 2.4 GHz, factory reset).

Type:  it's on a 5GHz wifi, is that a problem?

Expect: yes - the Hub 2 does not support 5 GHz-only networks.
